# Bundled Image Attribution

Images in this directory are drawn in the header of generated letters. A
missing file is skipped, so the template still renders without it.

| File | Subject | Source and rights |
|---|---|---|
| `scesi-logo.png` | SCESI logo | Public logo of the Sociedad Científica de Estudiantes de Sistemas e Informática (UMSS), supplied by a SCESI member for SCESI correspondence. All rights remain with SCESI. |

The renderer also looks for `umss-logo.png` and places it on the left side of
the header. Add it only after confirming the university permits its use.
